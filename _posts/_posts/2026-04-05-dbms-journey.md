If someone had told me a year ago that I'd be genuinely excited about databases, I wouldn't have believed them. But here I am.

## What is DBMS?

DBMS stands for Database Management System — it's the technology behind storing, organizing, and retrieving data efficiently. From hospital records to social media platforms, databases are everywhere.

In my 2nd semester at UET Faisalabad, DBMS became one of my most important and interesting subjects.

## Getting Started with MySQL

My first introduction to databases was through **MySQL** — one of the most widely used relational database management systems in the world.

Learning MySQL felt like learning a new language. At first, commands like `SELECT`, `INSERT`, `UPDATE`, and `DELETE` seemed intimidating. But slowly, things started clicking.

Writing my first query that actually returned data from a table was a small but satisfying victory:
```sql
SELECT * FROM students WHERE city = 'Lahore';
```

Simple — but it felt powerful.

## Working with WAMP Server

To practice MySQL locally, I used **WAMP Server** — a software that sets up a local web server environment on Windows. It made it easy to run and test databases on my own laptop without needing an internet connection.

Setting up WAMP for the first time was a bit confusing — ports, configurations, phpMyAdmin. But once it was running, everything became much smoother.

## What I've Learned So Far

- How to create and manage databases and tables
- Writing SQL queries — SELECT, INSERT, UPDATE, DELETE
- Understanding primary keys, foreign keys, and relationships
- Using WAMP Server for local database management
- Basic concepts of normalization and data integrity

## Why I Love Databases

There's something deeply satisfying about organizing data. As an introvert, I appreciate order and structure — and databases are exactly that. Everything has a place. Everything has a purpose.

DBMS has taught me that behind every app, every website, every system — there's a well-structured database making it all work.

## What's Next

I'm continuing to deepen my understanding of databases — exploring more complex queries, joins, and eventually moving towards more advanced topics like stored procedures and database design.

The journey has just begun — and I'm here for it.
