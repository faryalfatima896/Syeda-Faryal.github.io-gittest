Out of everything I studied this semester, SQL was one of those subjects that surprisingly did not feel as scary as I expected. Something about it just clicked. Unlike Python which took me weeks to feel comfortable with, SQL felt logical and readable from the very beginning.

## The Basics Came Quickly ⚡

The fundamental SQL commands became my new vocabulary:

- **SELECT** — retrieve data from tables
- **INSERT** — add new data
- **UPDATE** — modify existing data
- **DELETE** — remove data
- **CREATE** — build new tables

Learning these felt like learning a new way to ask questions. Instead of searching through data manually, you write a query and let the database do the work.

## JOINs — Where It Got Interesting 🔗

JOINs were where things got more challenging. Combining data from multiple tables, understanding which type of JOIN to use:

- **INNER JOIN** — matching records from both tables
- **LEFT JOIN** — all records from left table
- **RIGHT JOIN** — all records from right table

But Dr. Bilal Ahmad had a way of making even complex concepts approachable. He always taught through scenario based examples — real situations where you actually needed to JOIN tables to answer a meaningful question.

## Lab Sessions — Where It All Became Real 🖥️

The lab sessions were where everything came alive. We connected SQL to a proper server environment:

1. Installing SQL server
2. Connecting to the database
3. Creating tables and relationships
4. Running real queries
5. Getting actual results on screen

Writing a query and seeing the correct data appear — it made everything we had learned in theory come alive.

## Final Reflection #

What SQL taught me goes beyond just database commands. It taught me how to think about data — how it is structured, how tables relate to each other, how to ask the right questions to get the right answers.
