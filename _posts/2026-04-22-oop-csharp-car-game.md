When we were told we had to build a game using C# and Windows Forms, my first reaction was pure disbelief. I had never touched C# in my life before this. And yet here we were — assigned to create something that actually worked, actually ran, and actually felt like a game.

## The Challenge 🎯

I decided to build a **car game**. Completely alone. No group, no partner — just me, my laptop, and a lot of determination. Working alone was both the hardest and the most rewarding decision I made. Every problem that came up was mine to solve. Every breakthrough was mine to celebrate.

## Learning C# From Scratch 💻

C# felt very different from Python. Python had been my first programming language and I had gotten comfortable with its simple syntax. C# was stricter, more structured, more demanding. Everything had to be declared properly. Types mattered. Structure mattered.

## Windows Forms — A New World 🖥️

Windows Forms was a completely new experience:

- Designing the game interface
- Placing buttons and arranging elements
- Making the layout look like an actual game screen
- Handling click events and keyboard inputs

Getting everything to sit exactly where I wanted it took hours of tweaking and adjusting.

## The Four Pillars of OOP 🏛️

Throughout the entire project, the four pillars of OOP were my foundation:

- **Encapsulation** — keeping data safe and organized within classes
- **Inheritance** — building on existing code without rewriting everything
- **Polymorphism** — allowing objects to behave differently in different situations
- **Abstraction** — keeping complexity hidden and the code clean

Using all four pillars in a real project made me understand them in a way no textbook ever could.

## Building the Virus Element 🦠

The virus element of the game was one of the most interesting parts to build. Creating something that moved, that posed a challenge to the player, that had its own behavior — that required real logic and real coding.

## Final Reflection #

When the game finally ran — when the car moved, when the virus appeared, when everything worked together — the feeling was unlike anything I had experienced before. I had built something real. Something that worked. Something I had created completely on my own from scratch.
